# Repositorio Nexopolis - Snippet Manager

Un sencillo pero potente **gestor local de snippets** en Lua (y otros lenguajes).  
Creado para uso personal, seguro, rápido y totalmente offline, o no.

## Características
- Guarda y organiza snippets en **carpetas locales**.
- Editor avanzado con **Visual Studio Code**.
- Soporte para **atajos de teclado**:
  - `Alt + N` → Nuevo snippet  
  - `Ctrl + S` → Guardar  
  - `Ctrl + R` → Renombrar  
  - `Ctrl + B` → Borrar
- Sistema de **arrastrar y soltar** snippets entre carpetas.
- **Datos guardados localmente** (sin servidores externos).
- Interfaz inspirada en **Visual Studio Code**.

## Seguridad
Todos los datos se almacenan en el `localStorage` del navegador.  
Ninguna información se comparte ni se transmite por internet.

## Cómo usarlo
1. Abre el archivo `index.html` en tu navegador.  
2. Crea carpetas y snippets.  
3. ¡Tu progreso se guarda automáticamente!

## Tecnologías utilizadas
- HTML5 + CSS3
- JavaScript (Vanilla)
- Visual Studio Code (editor de código)
